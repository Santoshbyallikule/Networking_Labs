# Cisco Password Recovery

## Objective
Practice the Cisco IOS password recovery workflow in a controlled Packet Tracer lab.

## Learning Goals
- Understand configuration-register concepts
- Recover access to a router
- Preserve the existing startup configuration
- Set a new privileged EXEC password
- Verify the recovered configuration

Only perform recovery on devices you own or are authorized to administer.

Save as `Password_Recovery_Santosh.pkt`.
