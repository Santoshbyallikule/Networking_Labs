# IP Addressing & Subnetting

## Objective
Practice IPv4 addressing, subnet masks, default gateways and subnet calculations in Cisco Packet Tracer.

## Skills
- IPv4 addressing
- Network and broadcast addresses
- Usable host ranges
- Subnet masks
- Default gateway configuration
- Basic connectivity testing

## Verification
Use `ipconfig`, `show ip interface brief` and `ping`.

## Packet Tracer
Build the topology described in `topology.md`, configure the addresses in `addressing-table.md`, and save the completed topology as `IP_Addressing_Santosh.pkt`.
