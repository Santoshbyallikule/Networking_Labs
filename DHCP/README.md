# DHCP Server

## Objective
Configure a Cisco router as a DHCP server and allow clients to obtain IPv4 configuration automatically.

## Tasks
- Configure the LAN interface
- Exclude reserved addresses
- Create a DHCP pool
- Configure network and default gateway
- Verify client leases

## Verification
`show ip dhcp binding`
`show ip dhcp pool`
`show ip interface brief`

Save the completed Packet Tracer lab as `DHCP_Santosh.pkt`.
