# Packet Tracer Build Guide — OSPF

1. Open Cisco Packet Tracer.
2. Place the required routers, switches, PCs and server devices.
3. Connect devices using appropriate cables/interfaces.
4. Apply the addressing/configuration in this folder.
5. Verify connectivity and protocol state.
6. Save the finished topology using the filename specified in README.md.

The `.pkt` file should be created from your own Packet Tracer session so the topology is genuinely your lab work.
