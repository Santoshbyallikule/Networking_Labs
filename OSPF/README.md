# OSPF Single Area

## Objective
Configure OSPF Area 0 between routers and verify dynamic route learning.

## Tasks
- Configure router IDs
- Enable OSPF process
- Advertise connected networks
- Use Area 0
- Verify neighbors and routes

Verification:
`show ip ospf neighbor`
`show ip ospf`
`show ip route ospf`

Save as `OSPF_Area0_Santosh.pkt`.
