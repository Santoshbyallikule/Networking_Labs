# Standard and Extended ACLs

## Objective
Control traffic using Cisco IPv4 access control lists.

## Labs
- Standard ACL: filter traffic based on source IPv4 address.
- Extended ACL: filter traffic using source, destination and protocol/port.

## Verification
Use `show access-lists` and test permitted/denied traffic.

Save the Packet Tracer files as `Standard_ACL_Santosh.pkt` and `Extended_ACL_Santosh.pkt`.
